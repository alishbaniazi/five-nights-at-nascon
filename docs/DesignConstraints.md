Design Constraints

This project was intentionally implemented under strict Programming Fundamentals constraints.

The implementation intentionally avoids:

* User-defined functions
* Arrays
* Classes
* Dynamic data structures
* Advanced STL containers

The objective was to solve a complex simulation problem using only fundamental programming constructs such as:

* Variables
* Conditional statements
* Switch statements
* Loops
* Bitwise operators

These constraints required explicit state management and low-level logic while preserving the required functionality.

Future versions of this project may be redesigned using modern C++ principles such as object-oriented programming, modular architecture, and reusable components.
